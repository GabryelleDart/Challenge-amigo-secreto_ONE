**Desafio Acadêmico - Oracle Next Education (ONE) | Grupo 9**

Este projeto é o **primeiro desafio** do programa **Oracle Next Education (ONE)**|**Grupo 9**.  
É uma aplicação web de **Amigo Secreto**, criada para praticar **HTML, CSS e JavaScript**, proporcionando uma interface interativa.

A aplicação permite adicionar participantes, realizar o sorteio de um único amigo ou o sorteio completo, garantindo que nenhum participante receba a si mesmo. É possível remover amigos individualmente e resetar a lista.

---

## ✨ Funcionalidades

- 🟢 **Adicionar participantes à lista**  
- ⚠️ **Validação de campos vazios**  
- ❌ **Impede nomes duplicados**  
- 🗑️ **Remover participantes individualmente (botão ❌)**  
- 🎯 **Sortear um único amigo**  
- 🎲 **Sorteio completo (pares entre todos os participantes)**  
- 💬 **Feedback visual e mensagens animadas**  
- 🔄 **Resetar lista de participantes**  
- 📱 **Interface moderna, clara e responsiva**  

---

## 🛠️ Tecnologias Utilizadas

- 🌐 **HTML5** → Estrutura da aplicação  
- 🎨 **CSS3** → Estilização, layout responsivo e animações  
- ⚡ **JavaScript (ES6)** → Lógica de sorteio, validações e interatividade

## 🔑 Funcionalidades Detalhadas
➕ Adicionar Participantes

    Digite o nome e clique em Adicionar
    
    Campo vazio gera alerta
    
    Nomes duplicados não são permitidos

🗑️ Remover Participantes

    Cada participante listado possui botão de excluir
    
    Mensagem informativa confirma a ação

🎯 Sortear Um Amigo

    Seleciona aleatoriamente um participante
    
    Resultado destacado na interface

🎁 Sorteio Completo

    Embaralha a lista e gera pares justos
    
    Nenhum participante recebe a si mesmo
    
    Resultados aparecem com efeito fade-in

🔄 Resetar Lista

    Remove todos os participantes
    
    Mensagem confirma que a lista foi resetada
